## 研究概要
本研究は、街路空間における防犯性および安全性を高めるための
照明環境について検討したものです。
本研究は、街路空間における防犯性および安全性を高めるため、人の行動や心理、空間の特性に基づいた照明環境のあり方を明らかにすることを目的としたものです。従来の街路照明では、水平面照度や鉛直面照度などの数値基準を満たすことが重視されてきました。しかし、実際の街路空間における安心感や歩きやすさは、単に路面を明るくするだけで得られるものではなく、周辺の建物、空地、開口部、交差点などの見え方とも深く関係しています。
本論文では、まず、平坦な道路、橋梁、段差および集合住宅の共用部などを対象として、安全な歩行に必要な照明の条件を検討しています。次に、街路に隣接する空地などの「ボイド」に着目し、夜間歩行時の不安感や空間認知との関係を、現地調査、照明の点灯・消灯実験、模型実験およびシミュレーションを通して分析しています。
さらに、住宅や店舗などの建物に付随する光、特に窓や出入口などの開口部から街路へ漏れる光が、歩行者の安心感や街並みの明るさの評価に与える影響を検討しています。また、歩行者、自転車および自動車が交錯する交差点を対象として、横道や交差点の存在を事前に認識させ、危険を予測しやすくするための光環境について考察しています。
これらの調査と実験を通して、街路全体を均一かつ高照度で照らすのではなく、人の行為や場所ごとの特性に応じて必要な光を適切に配置するという照明計画の考え方を提示しています。防犯性、安全性、景観性および省エネルギー性を総合的に捉え、地域固有の生活や街並みに調和した、より豊かな夜間光環境の実現を目指した研究です。
歩行に必要な照明、街路周辺のボイド空間、建物に付随する光、
交差点の認知などに着目し、人の行動や心理に基づいた街路照明の
あり方を提示しています。
